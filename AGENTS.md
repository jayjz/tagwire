# Tagwire agent instructions

Tagwire is a local-first HVAC field-evidence prototype, not a diagnostic authority.
Read docs/INDEX.md and the relevant specification before edits.

- Inspect repository status and existing work before modifications. Never discard user work.
- Scope changes to the requested milestone. Do not add agent frameworks, model training, cloud services, or integrations without demonstrated need.
- Preserve the Next.js-managed block above. For Next.js changes read the installed version-matched docs in node_modules/next/dist/docs/.
- Raw technician statements, measurements, photos, and audio are evidence. Model-generated interpretations are proposals, never source evidence.
- Explicitly distinguish unknown, reported, observed, verified, proposed, authorized, ordered, and scheduled states. Never infer a completed action from intent or agreement.
- Numeric 0 and null are different. Voltage presence (present/absent/unknown) is separate from voltage magnitude.
- All derived fields require source references. Unknown information stays unknown; contradictions require review.
- Human approval is required before a report is finalized. Never auto-authorize repairs, purchases, or safety-critical actions.
- Do not commit identifiable customer details, credentials, audio, or real service-call photos. Use fictional fixtures.
- Keep capture durable without connectivity; processing can be deferred. Design capture sources as interchangeable adapters.
- Add focused tests for behavior changes. Run available lint, typecheck, tests, and build; report what actually ran and what did not.
- Prefer simple modules, explicit schemas, and reviewable PRs. No broad refactors or dependency upgrades without approval.
